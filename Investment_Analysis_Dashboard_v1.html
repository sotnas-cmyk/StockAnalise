Pedido gerado

O botão "Executar análise" prepara o pedido. Copia-o e cola-o num novo chat do ChatGPT. O ChatGPT fará a pesquisa atualizada e executará o framework.

Como funciona

  1. Coloca o URL do Yahoo Finance.
  2. Clica em Executar análise completa.
  3. Clica em Copiar pedido para ChatGPT.
  4. Abre o ChatGPT e cola o pedido.
  5. Depois da análise, guarda o resultado no teu arquivo de análises.

Nota: esta versão não acede automaticamente ao Yahoo Finance nem chama uma API. O HTML é uma interface simples para organizar o processo e gerar o pedido correto.
