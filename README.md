# Kit de Análise Fundamental

Este diretório contém os ficheiros para utilizar o Framework Mestre.

## Ficheiros

### 1. Framework_Analise_Fundamental_v2.0.md

É o ficheiro principal.

Contém: - sequência da análise; - definições; - regras; - Magic
Formula; - Acquirer's Multiple; - DCF; - Reverse DCF; - SOTP; - regras
especiais para empresas com Financial Services; - margem de segurança; -
decisão final.

**Não alterar este ficheiro sem intenção de mudar o nosso método.**

### 2. Watchlist.md

Lista as empresas que estamos a acompanhar.

Serve para: - preços; - valuation; - preços de entrada; - estado da
tese; - data da última análise.

### 3. Analise_Empresa_Template.md

Template para guardar uma análise individual.

Exemplo: `HRB.md` `DECK.md` `CAT.md`

### 4. README.md

Este ficheiro.

# Workflow recomendado

## Análise de uma empresa

1.  Abrir um novo chat.
2.  Carregar:
    -   Framework_Analise_Fundamental_v2.0.md
    -   opcionalmente Watchlist.md
3.  Pedir:

> Analisa \[EMPRESA\] (\[TICKER\]) usando integralmente o Framework
> Mestre. Pesquisa os dados mais recentes disponíveis, não saltes etapas
> e adapta o método de valuation à estrutura da empresa. No final
> apresenta Bear/Base/Bull, Reverse DCF ou Reverse SOTP, margem de
> segurança e preços máximos de entrada.

------------------------------------------------------------------------

## Análise de várias empresas

Carregar o Framework e pedir:

> Analisa \[LISTA DE EMPRESAS\] usando o Framework Mestre. Faz primeiro
> a análise individual e depois apresenta uma tabela comparativa e
> ranking final.

------------------------------------------------------------------------

## Atualização de uma empresa

Carregar: - Framework; - análise anterior.

Pedir:

> Atualiza esta análise com os dados mais recentes. Mantém as premissas
> estruturais que continuam válidas e identifica explicitamente o que
> mudou. Compara receita, EBIT, margens, FCF, FCF/share, dívida, ações
> em circulação, crescimento, riscos e valuation. No final diz se a tese
> melhorou, manteve-se ou deteriorou-se.

------------------------------------------------------------------------

# Regra importante

Não pedir apenas:

> "Qual é o valor da empresa?"

Pedir sempre a execução do Framework.

O objetivo é impedir que: - um P/E baixo; - um FCF excepcional; - uma
previsão de crescimento otimista; - ou um DCF isolado

domine a decisão.

# Regra de atualização

Quando uma empresa já tiver uma análise anterior, guardar a versão
anterior e comparar:

**Anterior → Atual → Mudança → Impacto na tese**

O objetivo não é simplesmente recalcular o valuation.

É perceber:

> **A empresa mudou, o preço mudou, ou ambos?**
